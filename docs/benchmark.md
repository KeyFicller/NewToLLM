# Benchmark: PyTorch vs LibTorch

- date: 2026-10-21
- machine: Linux x86_64, cpu
- PyTorch: 2.14.1+cu130 (LibTorch version: see `sandbox verify`)
- CPU only, threads = 8, iters = 5 (warmup 2)
- generated by `python tools/benchmark.py --write`

Notes:
- Measured on a shared 8-vCPU Linux box (no GPU), with PyTorch 2.14.1 vs LibTorch 2.10.0+cpu. Because the versions differ,
  this compares the two runtimes as installed, not the language bindings alone. Treat differences of about 10–20% as noise.
- Re-run on your own machine with `python tools/benchmark.py --full --write` after building the C++ side.

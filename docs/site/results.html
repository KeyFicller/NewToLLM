② 训练曲线：两条线几乎完全重合

preset tiny，种子 123。步数 Python 288 / C++ 288；逐步训练 loss 最大误差 1.91e-06，验证 loss 最大误差 4.77e-07（门禁阈值 0.0001）。旧版因分词正则和 DataLoader 切分不同，同一配置下 Python 85 步、C++ 75 步。

③ 性能（中位数，毫秒，越短越好）

Linux x86_64 (cpu)，4 线程，预热 5 次后取 30 次的中位数；PyTorch 2.14.1+cu130 / LibTorch 2.10.0。同一 preset、同一种子、同一输入形状。两边版本不同、机器共享，这组数只说明“差距不大”，不说明谁更快；大部分时间花在同一套 ATen 内核里，C++ 主要省掉的是 Python 调度开销，小模型上更明显。
